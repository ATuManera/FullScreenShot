# FullScreenShot 0.1.0

Primera versión pública. Extensión de navegador para capturar páginas web
completas, con todo el procesamiento en local: sin servidores, sin cuentas,
sin telemetría.

## Qué incluye

- **Capture Visible**, **Capture Full Page** y **Capture Selected Scroll Area**
  en Chrome y Edge (Manifest V3, permisos mínimos, sin `<all_urls>` ni
  `chrome.debugger`).
- Exportación a **PNG** sin pérdida, **PDF híbrido** (la imagen de la captura
  más una capa de texto invisible tomada del DOM, que permite buscar,
  seleccionar y copiar, con enlaces clicables) y **Markdown** generado desde
  el DOM, no por OCR.
- Núcleo en Rust compilado a WebAssembly: geometría, planificación de
  capturas, composición en streaming y codificación PNG/PDF/Markdown.
- Modo **Reliable** para contenido con carga diferida, con detección de
  scroll infinito, y un límite de seguridad de tiles para páginas enormes.

## Correcciones de esta versión

- Área de scroll: el recuento del popup, la captura directa y el selector
  coinciden. Una región dentro de otra ya no oculta a la mayor, se cuentan
  más de cinco regiones, y los paneles colapsados y los cuadros de texto ya
  no se ofrecen como regiones.
- Capture Full Page captura entera una página cuyo `body` hace scroll
  (`html { overflow: hidden }`), en vez de una sola pantalla.

## Instalación

1. Descarga `fullscreen-shot-chromium-0.1.0.zip` de esta Release y
   descomprímelo.
2. Abre `chrome://extensions` (o `edge://extensions`) y activa el
   **modo de desarrollador**.
3. Pulsa **Cargar descomprimida** y elige la carpeta descomprimida.

## Limitaciones conocidas

- Safari: el análisis de compatibilidad y el script de conversión están
  listos, pero el proyecto de Xcode aún no se ha generado ni firmado.
- Todavía no está publicada en ninguna tienda de extensiones.
- El texto dentro de imágenes, `<canvas>` o `iframe` no entra en la capa de
  texto del PDF.
